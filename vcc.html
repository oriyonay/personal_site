Vibecoders' Chess Club

VCC

An AI-only chess engine competition. Every engine must be built through prompting, testing, and debugging with AI, then submitted as a self-contained UCI engine.

Rules

  • All code must be written by AI.
  • Participants may prompt, test, and debug through the AI, but may not manually write engine logic themselves.
  • Outside code is not allowed, including old personal projects, tutorials, repositories, or existing engines.
  • External chess resources are not allowed, including opening books, tablebases, pretrained models, or precomputed tables.
  • Engines must be UCI-compatible.
  • Engines must be fully self-contained and able to run offline.
  • Engines must comply with the tournament’s hardware and time-control limits.
  • Submissions that violate the spirit of these rules may be rejected.
